讀英文時遇到不懂的字，把它選起來、按 Ctrl+Alt+D，游標旁邊就會跳出 Cambridge 英漢字典的解釋：發音、詞性、英文定義、中文翻譯、例句。看完按 Esc，繼續讀。想記住的字按 Ctrl+S 存進單字筆記本。

01安裝

  1. 把 zip 解壓縮到一個固定的資料夾，例如「文件\Inset」。不要直接在壓縮檔裡面執行。
  2. 雙擊 Inset.exe。畫面上不會跳出大視窗，它會待在工作列右下角、時鐘旁邊的系統匣裡，圖示是白底黑十字。沒看到的話，按一下那裡的 ^ 展開。
  3. 如果出現「Windows 已保護您的電腦」，按「其他資訊」→「仍要執行」。這是因為這個程式沒有購買數位簽章，Windows 認不得是誰發行的，只會在第一次出現。
  4. 第一次查字時，視窗上方會寫 ONE-TIME SECURITY CHECK · CLOUDFLARE，這是 Cambridge 網站的安全驗證。等幾秒鐘它會自己通過，之後就不會再出現。

想每次開機就自動啟動：系統匣的十字圖示按右鍵 → Settings… → 勾選 Start Inset when I sign in to Windows。

02查字

怎麼叫出來什麼時候用
選取文字，按 Ctrl+Alt+D最常用。瀏覽器、Word、PDF、Notion 等大部分的程式都可以。
按 Ctrl+Alt+F，或點一下系統匣圖示打開搜尋框，自己打字，按 Enter 查。選不到字的地方用這個。

片語也可以查，最多 6 個字，例如 be subject to、take something for granted。

  • 1上方這一條：左邊是字典來源，同一個字查過兩次以上，右邊會顯示查了幾次（LOOKED UP 03）。按住這一條可以拖曳視窗。
  • 2UK、US 旁邊的喇叭：播放英式、美式發音。
  • 3 印章：存進筆記本的字會蓋上這枚章，外圈寫著分類和存的日期，中間是查過的次數。
  • 4Add to notebook（Ctrl+S）：把這個字存進筆記本，見下一節。
  • 5CAMBRIDGE：用瀏覽器打開 Cambridge 的原網頁。

操作

關閉按 Esc，或點視窗外面任何地方。
捲動滑鼠滾輪、方向鍵、PageDown。
再查詞條裡的字解釋或例句裡的英文字可以直接點，會在同一個視窗查那個字。
移動、調整大小按住上方那一條拖曳；拉視窗邊緣調整大小，下次會記得。想恢復原本大小，按上方的 DEFAULT SIZE，或在上方那一條連按兩下。

看到這些是什麼意思

淡紫色的一塊你查的是片語。Cambridge 把片語放在主要單字的詞條裡，淡紫色那一塊就是你要找的片語。
EN ONLY · NO CHINESECambridge 英漢字典沒有收錄這個字，顯示的是英英解釋，所以沒有中文。
DID YOU MEAN可能拼錯了。點下面列出的字就能查。
Selection is too long選太多字了。一次最多查 6 個字。
Can't read…終端機，以及用系統管理員身分執行的程式，讀不到選取的文字。改用 Ctrl+Alt+F 自己輸入。

03存字與單字筆記本

存一個字

在查字視窗按 Ctrl+S（或 Add to notebook），字就存好了，詞條右上角會蓋上印章。下方同時會展開一個面板，可以順手填：

CATEGORY分類，例如「建築」「雅思」。打一個新名字，就會自動新增這個分類。
STATUS熟悉度：New 新字、Learning 學習中、Known 已經會了。
NOTE筆記，例如在哪裡看到、怎麼記。

這些都可以不填，按 Done 或 Enter 收起來。之後要改，再按一次同一個按鈕；不想存了，按 Remove。

每個查過的字都會記次數，就算沒有存也一樣，所以常查的字之後一眼就看得出來。30 分鐘內重複查同一個字，只算一次。

打開筆記本

按 Ctrl+Alt+N，或系統匣圖示按右鍵 → Notebook。

  • 1分類：All words 是全部的字，點一個分類就只看那一類。New category 新增分類；在分類上按右鍵可以改名或刪除。刪掉分類時，裡面的字會變成 Uncategorized，不會不見。
  • 2搜尋與篩選：可以搜英文、中文或筆記內容；All / New / Learning / Known 依熟悉度篩選。
  • 3單字清單：LOOKUPS 是查過幾次。按住 Ctrl 或 Shift 可以多選，按右鍵可以一次移到某個分類、改熟悉度或刪除。Delete 刪除，Enter 或連按兩下重新查這個字。
  • 4右邊是選到的字：Look up again 重新查、Cambridge 開原網頁。分類、熟悉度、筆記都可以直接改，會自動存檔。
  • 5Export CSV：把目前清單上的字（有篩選就只匯出篩選後的）存成 CSV，可以用 Excel 打開，或匯入 Anki 做字卡。

左下角的 HOW TO USE 會打開這份說明。

04設定

系統匣圖示按右鍵 → Settings…

Shortcuts三個快捷鍵都可以改：點一下框框，再按新的組合鍵。跟別的程式衝突時會直接提示。Reset to defaults 恢復預設。
Appearance外觀：Same as Windows 跟著 Windows、Light 淺色、Dark 深色。
Startup開機自動啟動。

05常見問題

要錢嗎？要註冊嗎？
都不用。
我查了哪些字，會被上傳嗎？
Inset 不會把你的筆記本、設定或查字紀錄傳到任何地方，這些都只存在你的電腦。查字時，它是在內嵌的瀏覽器裡打開 Cambridge 網站，就跟你自己用瀏覽器查一樣，Cambridge 網站本身的統計和廣告程式也會照常載入。
沒有網路可以用嗎？
不行。字典內容是每次即時從 Cambridge 網站讀取的。
按了快捷鍵沒反應？
先看系統匣有沒有十字圖示，沒有的話代表 Inset 沒在執行，重新打開 Inset.exe。如果有，可能是那組快捷鍵被別的程式占用了，到 Settings… 換一組。
換電腦時，筆記本怎麼帶走？
先在系統匣按右鍵 → Quit Inset 關掉程式，再把 %AppData%\Inset\notebook.json 複製到新電腦的同一個位置。也可以用 Export CSV 匯出備份。
怎麼移除？
如果有勾開機啟動，先到 Settings… 取消勾選；系統匣右鍵 → Quit Inset；再刪掉 Inset 的資料夾，以及 %AppData%\Inset 和 %LocalAppData%\Inset 兩個資料夾。
